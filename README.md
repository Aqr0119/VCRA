# 无畏契约残局复盘助手

> 上传一段《无畏契约》残局视频，AI 帮你逐回合指出失误、给出能直接用的改进建议。

## 🎯 这是什么

打《无畏契约》的时候，残局输了经常说不清"到底是哪一步崩的"，自己盯着录像回看又慢又容易漏。

**无畏契约残局复盘助手**就是来干这件事的：你把残局视频丢进去，AI 像教练一样告诉你——这一回合你错在哪、当时有没有更好的选择、下次遇到同样情况该怎么打。

## ✨ 核心功能

- **一键上传**：上传残局录像，无需手动剪辑
- **AI 逐回合点评**：定位关键失误（走位、枪线、信息判断、道具使用等）
- **建议能落地**：不是"你打得太菜了"，而是"这里应该先插烟再进点"这种能直接执行的结论
- **结构化输出**：以清晰条目呈现，方便对照录像复看

## 🧠 它是怎么工作的

采用「看 / 评」两段式架构，把"观察"和"点评"拆开：

1. **看** —— 视觉模型（Qwen3-VL）先解析残局画面，把局势提取成**结构化信息**
2. **评** —— 再基于这些结构化信息，生成针对性的复盘点评

这样拆的好处是：模型不用"一边看一边瞎评"，点评更稳更准，两部分也能分别调优。

## 🚀 快速开始

**环境要求**：Python 3.10+，一个[阿里云百炼](https://bailian.console.aliyun.com/)的 API Key。

**运行**：

```bash
python app.py            # 请替换为你实际的启动命令
```

然后在浏览器打开终端里提示的地址，上传一段残局视频即可。
